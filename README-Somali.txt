# HOGAAMIYE 🌟 — Cusboonaysiinta YouTube

Faylkan `index.html` wuxuu ku darayaa qayb rasmi ah oo HOGAAMIYE YouTube ah.
Wuxuu sii adeegsanayaa `styles.css` iyo `script.js` ee repository-ga hadda jira.

## Sida loo geliyo GitHub (telefoonka)
1. Fur repository-ga HOGAAMIYE.
2. Fur `index.html`.
3. Riix qalinka (Edit this file).
4. Tirtir koodhkii hore oo ku beddel dhammaan waxa ku jira `index.html`-kan.
5. Riix **Commit changes**.

Ha beddelin `styles.css` ama `script.js`; cusboonaysiintan uma baahna.
