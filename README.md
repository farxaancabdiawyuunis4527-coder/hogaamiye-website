# HOGAAMIYE 🌟 — Website

**Iftiimi Maskaxda • Dhis Mustaqbalka**

Website Af-Soomaali ah oo loogu talagalay Diinta, Aqoonta iyo Dhiirigelinta.

## Faylasha
- `index.html` — Qaab-dhismeedka bogga.
- `styles.css` — Naqshadda iyo habaynta mobile-ka.
- `script.js` — Menu-ga mobile-ka iyo isdhexgalka bogga.

## Daabacaad
Mashruucu waa static website; uma baahna framework ama build step. GitHub Pages ayaa lagu daabici karaa.
